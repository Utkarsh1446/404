You can lose a photo game to the server that keeps the score.

notfound is a place-guessing game. You see a photo, drop a pin, and find out how far off you were. The payout used to live in a server file, so the score could change after the pin. On this build the place is committed on NEAR testnet before the guess, and the contract measures the distance and mints the NOTF.

One round: commit the place, pin the map, reveal. A gasless guest session does it without a wallet popup. The relayer pays the gas. A drop pays 25 NOTF from a pool contract to the closest pin inside 50 km.
