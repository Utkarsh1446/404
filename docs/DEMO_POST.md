You can lose a photo game to the server that keeps the score.

notfound shows a photo and you drop a pin. The old score lived in a server file, so it could change after the pin. On this build the place is committed on NEAR testnet before the guess. The contract measures the distance and mints NOTF. A close pin mints more. The fourth round of a UTC day burns 10 NOTF. Three free rounds, then the burn.

The public page is a demo. The pin you drop there is scored in the browser and does not mint. The mint you can open is a round that already settled: 1,329 m, 15 NOTF, transaction HQKG8AwbdcUcw2gcuAhN17TiPAZagmMVo7A4SYUeQXTK on testnet. A drop that already paid 25 NOTF from the pool is 95ETWNvtsPfCD4PjBswgP9wgePzZkUw1hxrfCFAnwN7.
