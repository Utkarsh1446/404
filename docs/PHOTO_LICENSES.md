# Photo licenses

The six round photos in `src/assets/places/` are the Street View fallback. They are used when `VITE_GOOGLE_MAPS_API_KEY` is empty. The same text is served at `/photo-licenses.txt` from the static build.

Each file is a 1280×800 JPEG crop of a Wikimedia Commons thumbnail. The crop is a modification of the original. The license of the original still applies. These files are not covered by the MIT license on the rest of the repository.
